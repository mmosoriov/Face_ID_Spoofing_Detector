# To run the demo:
1. unzip demo.zip
2. Open "Demo_spoof_detector.ipynb" in Colab
3. Connect to runtime and upload "model.pt" and "Demo_Dataset.zip" to /content (is the default dir)
4. After both files are uploaded, Run All


# To run training code( this is the one that includes the Cam -grad visualization)
1. Open "training_spoof_detector.ipynb" in Colab
2. Connect to GPU L4
3. Upload Dataset_Spoof_Detector.zip to /content (is the default dir)
4. Run All, it will need to uninstall some packages and install other versions, clikc restart session and run all if the message is prompted
